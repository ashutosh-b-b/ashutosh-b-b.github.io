## Overview
Dive into Deep Learning is an interactive deep learning book with code, math, and discussions. Originally implemented in PyTorch, JAX and TensorFlow.

## Features
Developed a comprehensive suite of deep learning architectures and core components from scratch in Julia, demonstrating a fundamental understanding of their underlying mechanics.

- Core Framework: Built foundational modules from scratch for model training, validation loops, and performance monitoring.

- Convolutional Neural Networks (CNNs): Implemented a range of computer vision models, from basic CNNs to complex architectures like ResNet and Inception.

- Recurrent Neural Networks (RNNs): Constructed various sequence models, including standard RNNs and their advanced variations: LSTMs, GRUs, and Bidirectional RNNs.

- Attention & Transformers: Implemented modern encoder-decoder architectures and the core components of the Transformer model, including Self-Attention and Multi-Head Attention, applying them to a machine translation task.

- Object Detection: Built a complete Single Shot Detection (SSD) model from the ground up, including the complex logic for anchor box generation and prediction.
