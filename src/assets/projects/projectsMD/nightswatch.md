### Overview
NightsWatch is a full stack docker containerised web application for tracking and benchmarking code regressions for a GitHub repository.

### Features 
- Interactive Regression Analysis: Features a web-based dashboard that interactively displays performance changes, allowing developers to instantly identify speed-ups and slowdowns.

- Historical Performance Graphing: Maintains a persistent graph of benchmark history, creating a visual timeline of code performance and making it easy to trace regressions back to their source.

- Containerized Deployment: Fully containerized with Docker, ensuring portable, scalable, and isolated deployment.
